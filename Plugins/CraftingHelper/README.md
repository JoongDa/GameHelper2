# CraftingHelper

独立的半自动洗词插件。只新增本插件文件，不修改 GameHelper Core 或其他插件。游戏内偏移、UI 路径和实际操作效果尚需使用者验证；本地构建通过不代表游戏验证通过。

## 独立构建

在仓库 `GameHelper2` 目录执行：

```powershell
dotnet build .\Plugins\CraftingHelper\CraftingHelper.csproj -c Release
```

若本机的预览版 SDK 在并行项目评估阶段静默失败，可使用单节点构建：

```powershell
dotnet build .\Plugins\CraftingHelper\CraftingHelper.csproj -c Release -m:1 -nr:false -p:BuildInParallel=false
```

使用项目自身的构建复制目标部署插件，无需把新项目加入现有解决方案。插件默认关闭，先配置停手条件，再显式开启。

Release 输出会部署到 `GameHelper/bin/Release/net10.0-windows/win-x64/Plugins/CraftingHelper/`。运行该输出目录的 GameHelper，在插件列表启用 CraftingHelper，并在它的设置中勾选“启用半自动洗词”。`logs/sessions.jsonl` 记录会话变化和点击，超过 2 MB 自动轮换；诊断反馈可附上这一文件。

## 使用流程

1. 打开主背包，将鼠标停在要使用的一堆通货上，手动右键。插件记录来源条目和数量；插件不会模拟右键，也不会自动选择或补充通货。
2. 确认界面已经记录来源，再悬停要洗的装备。开始前已经满足条件时不会点击。
3. 连续按住 Shift 3 秒启动，运行时继续按住。每次原地左键后等待来源消耗和新的有效词缀结果，再判断是否继续。
4. 命中立即停止；松开 Shift 随时停止。停止后必须先松开 Shift，才能开始下一轮。

相邻点击的随机最短等待为 **200～300 毫秒（0.2～0.3 秒）**，每次成功点击后只采样一次。读取延迟或帧耗时可以使实际间隔更长；不会补发积压点击。源堆耗尽、目标丢失、失焦、关闭背包、读取失败或达到执行上限都会停止。Escape 或新的手动点击会取消既有通货记录，需要重新右键记录来源。

未验证光标动作字段，因此记录右键来源不等于确认游戏已经选中通货。短促右键可能未被逐帧检测捕获；未显示来源时不得启动。完全相同的洗词结果无法与旧数据可靠区分时，会等待后超时停止，不能自动重试。

## 复用与边界

- 复用现有 Core 的游戏状态、面板 UI 和物品组件模型；缺少公开接口的部分集中在插件内的小适配器，仅按需读取来源和当前目标，不另扫整个物品列表。
- 通过项目编译链接复用 `../StashUtility/Data/EquipmentAffixTiers.cs`，通过链接复制复用其词缀 JSON。原文件不迁移、不修改，也不要求启用 StashUtility 或引用其运行 DLL。源码来源共用，运行时缓存独立。
- 原地左键和按键状态检测通过编译链接直接复用 PickupHelper 的 `Native.cs`，随机等待沿用时间戳调度。现有 Core 的 `MiscHelper.KeyUp` 发送键盘消息，不能代替鼠标左键。
- 不修改其他插件，因此**没有跨插件的全局输入互斥或节流**。使用前停用可能同时发送键鼠输入的 Autopot、AutoHotKeyTrigger、PickupHelper 等功能。
- 主背包路径默认候选为 `RightPanel → 5 → 36`；物品指针扫描范围默认候选为 `0x20～0x600`（高级设置按十进制输入 `32～1536`）。两者均可配置，需与当前游戏版本核对，无法可靠定位时保持关闭。
- 长按计时中移动到另一件装备也会停止，需要先松开 Shift 再重新开始，避免误接续到其他目标。

## 游戏内验证

先使用少量通货及可接受损失的装备逐项检查：

1. 保持“启用半自动洗词”关闭，在高级选项开启“显示悬停物品诊断”，确认主背包 UI 路径、悬停装备名称、通货名称和数量准确；右键通货能被记录，Escape、失焦或手动点击能取消记录。
2. 配置一个当前已满足的停手条件，开启插件后按 Shift 超过 3 秒，确认零点击。
3. 配置容易命中的条件并设置很小的执行上限，确认 3 秒前不启动、每次消耗一枚、词缀更新后才继续，命中后没有下一次点击。
4. 检查松键、移出目标、关闭背包、切换窗口和禁用插件均立即停止；保持 Shift 不会自动重新启动。
5. 检查最后一枚通货用尽、无变化、相同结果或读取超时均停止，不能退化为反复普通左键。检查插件不会移动鼠标或注入右键。

遇到识别错误或不确定状态，关闭插件并修正配置或提供日志后再测试。
